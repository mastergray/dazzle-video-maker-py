To reduce executable file size these menus are limited in
scope.  Please take the time to read the DAZZLE.DOC file, it
will show you how to get the most out of this program. Use the
'DAZZLE -?' command at the DOS prompt for an outline of
command line options. DAZZLE can create a new copy of
DAZZLE.DOC if you invoke it as 'DAZZLE -Z' at the DOS prompt!
The keyboard functions under these menu screens vary from the
actions when DAZZLE is actively displaying graphic screens.
Cursor movement is accepted from the arrow keys. The HOME key
jumps to the first menu or field, the END key jumps to the
last menu or field.  PAGE UP (PgUp), and PAGE DOWN (PgDn) keys
step from one menu to another. Note the display at the bottom
right of this text window, it has [PgDn], which means that
more pages are available. ENTER accepts any input you provide.
To exit a menu subsystem, press the same key that activated
that system.  Therefore, to exit HELP press F1 again. To see
more help press the PgDn key.
The following keys can be used while in the 'Semi-Automatic' mode:
*F1      = Toggle HELP display.
*F2      = Toggle Configuration menu.
*F5      = Dump primary screen image to disk file.
 F8      = Toggle continuous drawing mode.
 F9      = Select next random image algorithm.
*Alt-F9  = Toggle between 'Automatic' and 'Semi-Automatic' mode.
            A multi-tone chirp indicates 'Semi-Automatic' is
            ready to begin image generation.
 F10     = Draw current image algorithm while key is pressed.
 Alt-F10 = Reinitialize the current image algorithm.
*Shf-F10 = Select new group of image colors.
*Ctl-F10 = Select new background colors.
Various Alternate and Control keys can be used in 'Semi-Automatic'
to manually select a specific image pattern for the F8 and F10 keys.
Refer to IMAGE SIZE configuration menus to match keys to images.
NOTE: keys marked with '*' are also active outside of the 
      'Semi-Automatic' mode of operation.
Each 'Fade' effect can be manually invoked by pressing the
specific keys listed in the FADE ENABLE configuration menu.
The P (Pan/Scroll fade) key will induce a random fade effect
when pressed in the 'semi-auto' mode.
Some fades are only available in VGA mode.
The following keys have special effects and are not listed
in the FADE ENABLE configuration menu:
H = Hold current display from fading (ignored in 'semi-auto').
N = Next display now, immediate clear of image display.
Press these letters without the ALT or CTL shift keys.
These are effective in 'Automatic' and 'Semi-Automatic' modes.
The F2 key activates the Configuration Subsystem. From it's menu
the image size of each drawing algorithm can be adjusted, and
specific 'fades' can be disabled. The number of images that are
displayed in the Auto Mode can be customized. It also allows the
saving or loading of files containing DAZZLE command scripts.

can be specified on the command line when DAZZLE is invoked to
cause the program to operate with the saved options. The program
will automatically load a file MTDAZZLE.DZL if it can be found.
Using an "*" character on the command line will prevent loading
of this file.
This is a text file that can be edited. It contains comments

one of these files and review it while viewing the menu presented
by the F2 key.
The TAB key initiates FREEZE mode, halting all activity within
the program.  While in FREEZE mode the TAB key toggles between
cycling and non-cycling of the colors of the displayed image.
Press SPACE to exit the FREEZE mode, and restore normal program
operation (console beeps).
HELP can be called when in FREEZE mode, but it will terminate
the FREEZE mode.
During the display press "+" or "-" to change the color cycling
speed. In VGA mode press "Page Up" or "Page Down" to change the
color cycling step range.
